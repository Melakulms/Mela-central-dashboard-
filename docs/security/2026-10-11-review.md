# Security and release review — 11 October 2026

Scope: source review and local tests of the learner UI, historical backend contracts, registration defaults, educator review, external links and Arena entry points. This is not a full penetration test or a fresh production database audit.

## Changes
- Registration is the first signed-out view. Existing session restore and password recovery remain higher-priority flows. Beta access codes and server eligibility are not bypassed.
- Unsafe external source links now use the shared URL validator; executable schemes, embedded credentials, control characters, direct IP/local-device targets and nonstandard ports are rejected.
- Teacher approval requires a test response, an attestation covering correctness/variants/rationale/age/language/fairness/rights and a note. Evidence is stored through the existing authenticated, subject-scoped review RPC. These UI requirements do not replace server authorization and cannot prove that a human actually performed the review.
- Existing decisions are displayed but are not automatically resubmitted under another teacher's identity. New approvals require a new attempt.
- The opportunity list no longer silently stops at 100 records; ordered pages are fetched and expired records are excluded.
- Eight Arena entry points expose seven stored types plus tournaments. This is a reconstruction from the backend, not confirmation of an unseen original eight-type specification. Five matchmaking types use the established RPC. New hosted join controls fail closed.

The UI pause does not revoke or secure a historical RPC by itself.

## Human review coverage
The v18 review queue accepts a program filter and returns at most 100 slices. The UI now exposes that filter and an explicit truncation warning. This reaches later subjects but does not implement within-subject pagination. A cursor-paginated, subject-authorized RPC is still required if a subject exceeds 100 slices. No live grading keys were exported, no questions were automatically approved, and no reviewer identity was fabricated.

## Resource directory evidence
The claimed 2,000-site dataset was not found in either repository or Library search. The new seven-source starter directory is explicitly separate. Searchable official sources: MIT OpenCourseWare, OpenLearn, IBM SkillsBuild, Khan Academy, freeCodeCamp, UN Careers and UN Volunteers. Provider pages were researched on 11 October 2026. This does not guarantee individual postings, country eligibility, fees, uptime or safety after redirects. Repair of the original directory requires its file or location. Preserve original IDs; check duplicate URLs, redirect destinations, domain ownership, HTTP outcomes and editorial suitability before publishing. Browser CORS is not evidence that a website is broken; external sites open as links, not embedded fetches.
